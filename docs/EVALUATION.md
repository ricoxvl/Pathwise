# Evaluation plan and verified boundaries

## Executable automated coverage

`tests/engine.test.mjs` covers fictional profile schema validation, prerequisite violations, credit accounting, unscheduled requirements, workload warnings, solver outputs, advisor text and rule IDs.

## Unverified outcomes

No real university requirement set is loaded. No official academic risk accuracy is claimed. No user study, advisor-validated risk detection rate, student adoption or reduction in planning time is claimed for this release. A successful build or fictional fixture test cannot validate official graduation guidance.

## Proposed next study

1. With permission, freeze versioned real catalog rules for one supported program and record where each source excerpt came from.
2. Assemble anonymized/hypothetical profiles, including transfer edge cases, dual-credit overlap, minimum grades, substitutions and prerequisites.
3. Ask qualified reviewers to label known risks and compare engine recall, precision and **false all-clear** count.
4. Evaluate time to identify a risk, correct explanation comprehension, calibrated confidence, and successful advisor-brief preparation against normal resources.
5. Publish method, sample size, uncertainty and limitations before quoting external metrics.

The initial solver is conditional: it checks known demo prerequisites and workloads only. Future term offerings are assumptions, not availability confirmations.
